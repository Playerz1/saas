# CrieAI - Dashboard SaaS

Projeto de dashboard SaaS em um único arquivo HTML autossuficiente.

## Estrutura

```
historico/
├── dashboard.html   # Página completa (HTML + Tailwind + Lucide + JS)
├── README.md        # Este arquivo
└── alteracoes.md    # Lista de mudanças implementadas
```

## Funcionalidades

- Saudação por horário com nome do usuário (Boa madrugada / Bom dia / Boa tarde / Boa noite)
- Perfil com avatar + @ + nome (edição com caneta, imagem da galeria)
- Filtro de data (Desde / Até) em modal preto e branco
- Botão Atualizar em tempo real com "Atualizado às HH:MM"
- Métricas animadas (Faturamento, Recorrência, Ticket Médio, Total de Vendas)
- Gráfico de evolução do faturamento
- Sidebar desktop com navegação e perfil embaixo de Sair
- Bottom nav mobile
- Topbar mobile com ícone Code (vermelho sobre fundo preto) e nome "riqwvon"

## Tecnologias

- HTML5
- Tailwind CSS (via CDN)
- Lucide React (ícones via CDN)
- JavaScript vanilla (sem build, sem Node.js)
